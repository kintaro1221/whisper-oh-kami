# WhisperOhKAMI 特定商取引法に基づく表記

最終更新日: 2026-06-30

本ページは、特定商取引法（通信販売）に基づき、本サービス「WhisperOhKAMI 招待制先行販売」に関する事項を表示するものです。

---

## 販売事業者・運営統括責任者

個人事業主として運営しています。販売事業者名（氏名）および運営統括責任者の氏名は、特定商取引法施行規則第23条に基づく **請求に応じた開示** とし、下記「連絡先」のメールアドレスにご請求いただいた場合に遅滞なく開示します。

## 所在地

特定商取引法施行規則第23条に基づき、上記同様、ご請求に応じて遅滞なく開示します。

## 連絡先

- メール: 本サービスのランディングページに掲載のメールアドレス（運用中の窓口）
- 本サービスは個人開発（趣味スコープ）で提供しているため、お問い合わせは **メールのみ** で受け付けます（電話窓口はありません）。電話番号についても、特定商取引法施行規則第23条に基づき、ご請求があった場合に遅滞なく開示します。
- 返信は **ベストエフォート** で行います。対応・期日は保証しません。

## 販売価格

**2,980円**（支払総額。日本円建て・JPY。消費税を含みます。）

- 買い切り（売り切り）方式です。サブスクリプション課金はありません。
- 当方はインボイス制度（適格請求書等保存方式）の登録事業者ではないため、**適格請求書を発行できません**。Stripe から自動送付される領収書（Stripe Receipt）は、適格請求書の要件を満たしません。

## 商品代金以外に必要な料金

- 当方が直接請求する追加料金（手数料・送料等）はありません（ダウンロード提供のため送料は発生しません）。
- ただし、お客様が任意で **BYOK（お客様自身の API キー）** による外部 AI/STT 機能を有効にする場合、お客様が契約する以下の外部サービスの **従量課金は、お客様ご自身のご負担** となります。当方はこれらの料金を一切受領・代理徴収しません。
  - Google Gemini API（任意。BYOK）
  - Deepgram API（任意。BYOK）
- BYOK 機能を有効にしない既定構成（trial / local-whisper / local-ollama）では、上記の外部従量課金は発生しません。

## 支払方法

- **Stripe（Stripe, Inc.）** を通じたクレジットカードによるお支払い
- 当方は Stripe を **決済プロセッサとして** 利用しており、本サービスの販売事業者は当方（個人事業主）です。決済代行プラットフォームによる代行販売ではありません。
- 当方はお客様のクレジットカード情報を取り扱いません。カード情報の処理・保持は Stripe が行います。

## 支払時期

ご購入手続き時にお支払いが確定します（Stripe の決済処理に従います）。

## 引渡時期（提供時期）

- 決済完了後、ブラウザ上で **アクセス URL** を発行します。
- アクセス URL の初回取得は決済完了から 24時間 以内に行ってください。
- アクセス URL から、Windows 11 x64 向けインストーラ・対応ソース zip・GPL-3.0 ライセンス・THIRD_PARTY_NOTICES・インストール手順・ビルド手順・ロックファイル zip・マニフェスト JSON を順次ダウンロードいただけます。
- 24時間以内の初回取得を逃した場合は、連絡先メールに「アクセスリンク再発行希望」と件名を入れてご連絡ください。事務的な再発行で対応します（製品サポートとは別の事務手続きです）。

## 返品・キャンセル（返金）について

- 本サービスはダウンロード提供のデジタル商品です。お客様のご都合（「期待した機能ではなかった」「実機環境で性能が出ない」等の主観的理由）による返金には応じられません。
- ただし、**ご購入から 7日 以内** で、かつ **動作環境（Windows 11 x64）を満たした端末でのインストール・初回起動の技術的な不具合** により本ソフトが起動できない場合に限り、ご返金に応じます。
  - 動作環境（Windows 11 x64）を満たさない端末でのインストール失敗は対象外です。
  - 連絡先メール宛に、症状・お試しいただいた内容・ご利用環境（Windows のバージョン、エディション、CPU/メモリ概要）をご連絡ください。
- 返金は Stripe を通じて、お客様の決済手段に対して全額返金します。
- 返金時に Stripe が当方に返還しない決済手数料が発生する場合、当該手数料は **当方が負担** します。お客様の追加負担はありません。

## 動作環境

- **対応 OS: Windows 11 x64 のみ**（Windows 10、macOS、Linux は対象外です）
- ビルドは **未署名** です。初回起動時に Windows SmartScreen の警告が表示されます。「詳細情報 → 実行」で起動できます。

## 申込みの有効期限

- 本サービスは **20名限定** の招待制先行販売です。
- 販売枠が埋まり次第、新規受付を終了します。当方は予告なく販売を終了・休止することがあります。

## サポート

- 本サービスに **個別サポートは含まれません**。バグ報告・要望は連絡先メールで受け付けますが、返信・対応はベストエフォートです。

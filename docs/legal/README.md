## 確定事項（2026-06-30 時点）

- **販売価格**: 2,980円（支払総額、JPY、消費税込み）。買い切り（売り切り）。
- **決済**: **Stripe**（決済プロセッサ。Merchant of Record ではなく、当方が販売事業者）。当方はインボイス制度未登録のため適格請求書は発行しません。Stripe Receipt が領収書となります。
- **配布**: Cloudflare R2 で保管された Windows 11 x64 向け一括ダウンロード（インストーラ＋対応ソース＋ライセンス＋NOTICES＋ガイド＋ビルド手順＋ロックファイル＋マニフェスト）。
- **アクセス**: 決済完了後にアクセス URL を発行。初回取得は 24時間 以内。
- **返金**: 購入から **7日** 以内かつインストール・初回起動の技術的不具合のみ。Stripe が返還しない手数料は当方が負担。
- **動作環境**: **Windows 11 x64** のみ。ビルドは未署名（SmartScreen 警告あり）。
- **ライセンス**: ソフトウェア本体は **GPL-3.0**（対応ソースを同梱）。アクセス URL は購入者本人にのみ発行される事務的認証情報で、共有不可（GPL の再配布権の範囲外）。ダウンロード後のバイナリ・対応ソースは GPL に基づき自由に再配布可能。
- **サポート**: 個別サポートは含まれません（ベストエフォート対応）。
- **販売数**: 20名限定。
- **販売者情報**: 特定商取引法施行規則第23条に基づき、請求があり次第、メールにて遅滞なく開示。
- **BYOK**: Gemini / Deepgram の API 利用料はお客様負担（本価格に含まれません）。
- **将来の v1.x**: 提供される場合は本サービスに含めますが、リリース回数・機能・時期の保証はありません。

## やらないこと（明示的に scope 外）

- **コードサイニング**: 本サービス（招待制先行販売 2,980円）のスコープでは提供しません。後続の一般販売（JPY 4,980 フェーズ）に繰延。
- **有償の専門家による法務スポットレビュー**: 後続の一般販売フェーズに繰延（本サービスは趣味スコープのため）。
- **電話サポート / セットアップ支援 / 訪問・画面共有**: 個別サポートには含まれません。
- **個別の永続的ホスティング約束**: ローカルバックアップの保持をお願いし、当方は合理的な事前告知のうえサービスを見直すことがあります。

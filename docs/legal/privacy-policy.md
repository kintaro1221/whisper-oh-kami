# WhisperOhKAMI プライバシーポリシー

最終更新日: 2026-09-08

本ポリシーは、個人開発者（以下「当方」）が提供するデスクトップアプリ「WhisperOhKAMI」（以下「本アプリ」）および本アプリの先行販売（以下「本サービス」）のランディングページ・販売バックエンドにおける、個人情報・データの取扱いについて定めるものです。

本ポリシーは、現行の本アプリおよび本サービスの実装に基づき作成しています。実装ベースの詳細な経路図は [データフロー](/legal/data-flow) を truth anchor として参照してください。本ポリシーは法的助言ではありません。

## 1. 設計上の原則

### 1.1 会話データの送信と更新確認

本アプリの既定構成（API キー未設定の trial モード、または `local` provider mode）では、お客様の音声・文字起こし・操作情報を当方が運営するサーバへ送信する仕組みは存在しません。具体的には次のとおりです。

- 本アプリは利用状況を収集するテレメトリ（行動ログ送信）の仕組みを持ちません。
- 本アプリは自動クラッシュレポートの送信機能を持ちません。
- 本アプリは起動時に、当方が Cloudflare 上で提供する `https://whisperohkami.pages.dev/api/release/latest` へ GET リクエストを送り、更新の有無を確認します。リクエストに音声・文字起こし・画面内容・API キー・アプリ固有の利用者識別子は含めません。Cloudflare は通信に伴う IP アドレス、リクエスト時刻、HTTP ヘッダー等の通信情報を受け取ります。本説明はアクセスログの有効化や保存期間を示すものではありません。

### 1.2 端末外への送信が発生する条件（例外の整理）

一方、お客様が以下を選択された場合は、選択した経路で端末外への送信が発生します。これは **お客様の選択** に基づくものであり、当方が運営するサーバを経由するものではありません。

- **BYOK（Bring Your Own Key）**: お客様自身が契約・発行した Google Gemini / Deepgram / Groq の API キーを本アプリに設定された場合、当該経路で音声・transcript 等が各社のサーバへ直接送信されます。
- **Whisper モデル・Ollama モデルの初回取得**: 既定の `Xenova/whisper-tiny` 等の Whisper モデルは、初回のみ Hugging Face Hub から取得されます。Ollama モデルは、お客様が手動で `ollama pull` を実行された場合のみ Ollama サーバから取得されます。

これらの経路で送信されるデータの種類・送信先・コード位置の対応は、[データフロー](/legal/data-flow) をご参照ください。

### 1.3 本サービス（ランディングページ・販売バックエンド）の構成

本サービスは、ランディングページの閲覧・購入・成果物配信を行うために、後述「3. 本サービスで利用する第三者サービス」に列挙する外部サービスを利用します。

## 2. 本アプリにおける音声・文字起こしデータの流れ

本アプリは、商談相手の発話を聞き取り、文字起こし（transcript）を行い、画面上で 5 要素のヒアリング進捗を補助表示します。データがどこへ行くかは **お客様が選んだ動作モード** によって決まります。

### 2.1 trial モード（既定起動時 / 会話データは端末内）

- 音声認識は端末内の Whisper パイプラインで処理されます（`src/utils/localai.js`）。
- 5 要素 regex 判定は端末内で処理されます。
- 会話データを当方が運営するサーバへ送信することはありません。
- Whisper モデルの初回ダウンロード時に Hugging Face Hub と通信するほか、起動時に前述の更新確認を行います。

### 2.2 local-ollama モード（会話データは端末内、Ollama 既存セッションを利用）

- LLM 推論をローカルの Ollama で実行します（既定 `http://127.0.0.1:11434`、`src/storage.js`）。
- お客様が Ollama のホストを 127.0.0.1 以外（別の PC やサーバ）に設定された場合、文字起こしと会話内容はそのホストへ送信されます。
- Whisper 文字起こしも端末内です。
- このモードでも起動時に前述の更新確認を行います。
- お客様が手動で `ollama pull` を実行された場合のみ Ollama サーバとの通信が発生します。

### 2.3 byok モード（お客様自身のキーで各社へ直送）

- お客様が **Gemini API キー** を設定された場合、本アプリは Google Gemini API（米国）と通信します（`src/utils/gemini.js`、`src/utils/discoveryEvidenceLLM.js`、`src/utils/keyVerify.js`）。音声・transcript・画面（取得時）が、お客様のキーで各社に直送されます。**当方はこれらのデータを受領しません。**
- お客様が **Deepgram API キー** を設定し、`sttMode='cloud'` を有効にされた場合、本アプリはマイク音声および商談相手の音声を Deepgram WebSocket（米国、`wss://api.deepgram.com/v1/listen`、`src/utils/deepgram.js`）に直送します。**当方はこれらのデータを受領しません。**
- BYOK 経路では、データの取扱い・保存・学習利用の有無は **お客様と各 AI/STT サービス提供者との間の契約・プライバシーポリシー** に従います。利用前に各社の規約をご確認ください。

### 2.4 端末内に保存されるデータと削除

商談ごとの文字起こし・AI の助言・画面分析の結果は、お客様の PC の `%APPDATA%\whisper-oh-kami-config\history` に平文の JSON ファイルとして保存されます（当方へは送信されません）。自動削除は行いません。アプリの「設定 → プライバシーとデータ → すべてのデータを削除」を実行すると、この設定フォルダ全体（履歴・API キー・設定）と、旧バージョンの設定フォルダを削除します。Whisper モデルのキャッシュと、サポート用にお客様が書き出したファイルは削除されません。

### 3.1 D1 に保存される情報の限定

Cloudflare D1 の `orders` テーブルには、以下のみが保存されます。

- Stripe 識別子（`session_id`、`payment_intent_id`、`payment_link_id`、`price_id`）
- 不透明なアクセス状態（`access_id`、`access_generation`、`claim_open_until`、`claimed_at`）
- entitlement 状態（`entitlement_line`、注文ステータス: `paid` / `refunded` / `disputed` / `revoked`）
- タイムスタンプ（`created_at`、`updated_at`、`revoked_at`、`revoked_reason`）

お客様の **氏名・住所・電話番号・カード情報・メールアドレスは D1 には保存しません**。これらの一部は Stripe 側に残ります。

### 3.2 カード情報の取扱い

カード情報は **Cloudflare（D1 / R2 / Pages Functions / Turnstile）には一切入りません**。Stripe が直接処理します。

### 3.3 Gmail の用途の限定

Gmail は、本サービスの事務連絡（購入前のお問い合わせ・アクセスリンクの事務的再発行・問い合わせ・返金申請・特定商取引法に基づく開示請求への返信）の窓口としてのみ利用します。商品の個別サポート（インストール手順案内・トラブルシュート等）は本サービスに含まれません（`docs/legal/terms-and-sales.md` 第6条）。

## 4. 保持期間

本サービスで取得・記録されるデータの保持期間は以下のとおりです。

| データ種別                                                                          | 保持期間                                                       |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 処理済み Stripe `event_id` および安定な outcome code（D1 `stripe_events` テーブル） | **90日** 後に削除                                              |
| `orders` テーブルの注文識別子・entitlement 状態                                     | 有償ダウンロードアクセスが稼働している間、保持                 |
| 終了後の取引証跡（金額・日時・取引相手・取引対価等、会計・税務上必要な範囲のもの）  | 取引の発生から最長 **7年**                                     |
| 返金・チャージバック・法的保全の対象となる取引記録                                  | 上記期間によらず、保全の必要が解消するまで（早期削除しません） |

### 4.1 7年保持の根拠

**国税庁** の取引関係書類の保存に関する一般的取扱い（法人税法施行規則第59条、所得税法施行規則第63条、消費税法施行令第50条等）に準じます。当方は、有償取引に伴う書類（注文情報、領収書、契約書類等）を、取引の発生から最長 7年 まで保管することがあります。

なお、D1 は注文状態の運用用途のテクニカルストレージとして利用するものであり、会計法令上要請される正式な記録媒体としては別途、Stripe Dashboard のエクスポートおよび会計ソフト等で当方が管理します。D1 上のデータは、それらの会計記録の補助情報として 7年 まで保持されることがあります。

## 5. 商談相手（第三者）の音声・個人情報の取扱い — お客様の責務

本アプリは、商談相手の発話を聞き取ることを前提とします。商談相手の音声やそこに含まれる個人情報の取扱いについては、**本アプリの利用者であるお客様が管理者としての責任を負う** ことになります。当方は、お客様と商談相手との間の会話の内容・取扱いについて関与せず、これを把握する手段も持ちません。

- **録音・記録について**: 日本では、会話の当事者自身による録音は一般に違法とはされにくいと整理されています。もっとも、これは一般的な整理であり、個別の事情によって評価は変わり得ます。
- **越境移転について**: BYOK で Gemini（米国）または Deepgram（米国）を利用された場合、商談相手の音声 / transcript が日本国外へ移転されます。第三者の個人データを外国にある第三者へ提供する場合、個人情報保護法上、本人の同意取得等の対応が必要となり得ます。BYOK 経路を業務で使う場合はこの点に特にご注意ください。
- **既定構成で利用される場合**: trial モード / local モード（`sttMode='local'`）で利用される場合、商談相手の音声は端末外に送信されません。詳細は [データフロー](/legal/data-flow) をご参照ください。

詳細な行動ガイダンスは `docs/legal/recording-guidance.md` をご参照ください。

## 6. 個人情報の開示・訂正・削除等のご請求

当方が保有するお客様の個人情報（主に事務連絡で受領したメール等の情報、および本サービスのバックエンドが保存する注文状態）について、内容の開示・訂正・利用停止・削除などをご希望の場合は、下記の窓口までご連絡ください。本人からのご請求であることを確認のうえ、法令に従い、合理的な範囲で対応します。

- 受付窓口（メール）: 本サービスのランディングページに掲載のメールアドレス
- 本人確認: Stripe 決済時に登録されたメールアドレスからのご連絡をもって確認します。決済情報を Stripe 側で確認のうえ、注文と本人性を照合します。
- 対応目安: ベストエフォート。

なお、4-1 に記載のとおり、会計・税務上の保存義務に該当する範囲（取引証跡）については、その保存期間中、削除のご請求にお応えできない場合があります。

## 7. アクセス解析・Cookie

本サービスのランディングページにおけるアクセス解析・Cookie の利用は、現時点では **特段の解析ツールを導入していません**。配信基盤の Cloudflare は IP アドレス・リクエスト時刻・HTTP ヘッダー等の通信情報を受け取りますが、当方が独自にお客様の行動を解析する仕組みは導入していません。本説明は Cloudflare のアクセスログの有効化や保存期間を示すものではありません。

将来、アクセス解析ツール（例: Cloudflare Web Analytics 等）を導入する場合は、本ポリシーに追記のうえ、ランディングページ上でも明示します。
